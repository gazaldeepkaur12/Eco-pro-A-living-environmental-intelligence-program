# Data Dictionary

| Variable | Description | Unit / Range |
|---|---|---|
| plant_id | Identifier for the monitored plant | Text |
| temp | Environmental temperature | °C |
| humidity | Relative humidity | % |
| soil | Estimated soil moisture | 0–100 % |

## Notes

The current dataset is simulated.

Soil moisture values are generated through a potentiometer in the
Wokwi simulation and represent relative moisture levels rather than
calibrated volumetric water content.
