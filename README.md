# Eco-pro 🌱

An evolving environmental sensing project that grows alongside my learning journey.

Eco-pro began as a Python-based garden assistant and is gradually developing into a system that combines **Python, Arduino, environmental sensing, and eventually AI** to explore practical approaches to monitoring and responding to real-world environmental conditions.

The project currently focuses on collecting environmental data such as **temperature, humidity, and soil moisture**, processing those readings with Python, and generating simple plant-specific recommendations.

As I develop my programming and hardware skills, I plan to expand Eco-pro toward more advanced sensing, automation, and intelligent environmental decision-making.
