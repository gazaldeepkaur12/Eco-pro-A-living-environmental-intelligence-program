# Dataset analysis

The charts here summarize the simulated observations in `data/garden_log.csv`.

| Plant | Avg temperature (°C) | Avg humidity (%) | Avg soil moisture (%) |
|---|---:|---:|---:|
| Tomato | 38.8 | 67.6 | 83.4 |
| Basil | 29.7 | 75.2 | 72.8 |
| Cactus | 32.5 | 46.6 | 34.0 |
| Fern | 26.2 | 84.2 | 82.4 |

## What the graphs show

- The simulated plant profiles occupy different ranges of temperature, humidity and soil moisture.
- These differences are useful for demonstrating why the Python program uses plant-specific thresholds.
- The dataset is small and simulated, so the graphs show the behaviour of this example dataset rather than real environmental trends.
